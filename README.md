# マリカルナ — HTML / CSS / JavaScript版

## 編集するファイル

- `index.html`：ページの文章・構成・フォーム
- `style.css`：色・文字サイズ・レイアウト・アニメーション・スマートフォン対応
- `script.js`：スクロール演出・使い方タブ・フォーム送信
- `assets/product-reference.png`：製品画像

`index.html`をブラウザーで開くと表示できます。React・TypeScript・Tailwind・npm install・ビルドは不要です。画像とCSS/JSは相対パスなので、フォルダーごと移動できます。

## お問い合わせの受付

HTML/CSS/JSだけでは、訪問者から届く情報をサーバーに保存できません。画面用の3ファイルとは別に、任意で設置するプレーンJavaScriptの保存処理を `server/worker.js` にまとめています。

- 保存先：Cloudflare D1。DBバインディング名は `DB`。
- 静的ファイル配信用バインディング名は `ASSETS`。
- `server/schema.sql` は新規データベース専用です。既存データベースには再実行しないでください。
- フォーム送信先は同一サイトの `api/inquiries`。ページ本体と同じオリジンにAPIを設置してください。
- 静的ホスティングのみ、またはファイルを直接開いた場合、送信成功にはせずエラーを表示します。
- メール通知は未設定です。
- `server/` は公開する静的ファイルに含めず、サーバー側に配置してください。

以前のサイトは `../website/` に残しています。このフォルダーの編集だけでは既存の公開URLは更新されません。
